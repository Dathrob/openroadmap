# OpenRoadmap contributor instructions

Read `docs/SPEC.md` and `schemas/roadmap.schema.json` before creating a roadmap. Add `roadmaps/<slug>/roadmap.yaml` and `README.md`; do not hard-code content in React. Use original external links only; do not copy course content or invent URLs. Declare human, ai, or hybrid authorship and disclose AI provenance. Run `npm run validate`, `npm run typecheck`, and `npm run build` before a PR.
