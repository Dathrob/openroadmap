# OpenRoadmap Specification v0.1

OpenRoadmap is a domain-neutral static format for answering **know what to learn, know where to look**. A roadmap contains ordered sections, topics, and links to external resources. It does not host course content.

Every roadmap declares the spec, id, title, description, version, authorship, and sections. Authorship is `human`, `ai`, or `hybrid`; verification is separate. AI and hybrid contributions disclose provider, model, and version. Resources require a title and valid URL; recommendations are distinguished from alternatives.
